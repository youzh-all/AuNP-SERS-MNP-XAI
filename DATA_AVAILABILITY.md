# Data availability

This repository contains representative sample spectra, label definitions, dataset schema, preprocessing scripts, group-wise split summary, Transformer model implementation, evaluation scripts, XAI analysis utilities, and reference result tables.

The representative sample spectra are provided to demonstrate the data format and analysis workflow. They are not intended to reproduce the full model performance reported in the manuscript.

The full spectral datasets used for model training and evaluation are available from the corresponding author upon reasonable request.
